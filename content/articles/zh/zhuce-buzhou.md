# 注册步骤详解

加入 **Baatryn Öröö** 俱乐部只需 5–10 分钟。无论你在乌兰巴托、达尔汗还是额尔登特，按照[蒙古扑克下载](https://pppoker.mn/zh/articles/mongol-poker-xiazai/)教程操作，即可直接入座。

## 需要准备什么？

- 智能手机（Android / iOS）或电脑
- 网络连接
- 10,000₮ 以上首次[存款](https://pppoker.mn/zh/articles/cunkuan-tikuan-mongolia/)（开通账户后）
- Telegram — 有问题联系 [@BatrynOrooSupport](https://t.me/BatrynOrooSupport)

## 第 1 步：下载 PPPoker

1. 打开[蒙古扑克下载](https://pppoker.mn/zh/articles/mongol-poker-xiazai/)指南
2. Android：APK 或 Play Store
3. iOS：App Store
4. Windows / macOS：官方网站

遇到问题请查看：[应用安装与故障排查](https://pppoker.mn/zh/articles/pppoker-yingyong-cuowu/)。

## 第 2 步：创建账号

1. 打开 PPPoker
2. 点击"注册 / Sign up"
3. 输入手机号或邮箱
4. 设置密码 — 强密码，不与其他网站重复
5. 输入验证码完成验证

## 第 3 步：加入俱乐部

1. 点击"搜索俱乐部"或输入俱乐部 ID
2. 从 [@BatrynOrooSupport](https://t.me/BatrynOrooSupport) 获取 Baatryn Öröö 的俱乐部 ID
3. 发送申请 — 通常几分钟内审批
4. 获批后即可看到俱乐部牌桌

## 第 4 步：首次存款

1. 打开收银台（Cashier）
2. 选择 IBAN
3. 按指引转账 10,000₮ 以上
4. 10 分钟至 4 小时内到账

详情：[存款教程](https://pppoker.mn/zh/articles/cunkuan-tikuan-mongolia/)。

## 第 5 步：选择游戏

- **Hold'em** 9-max — 新手请先读[规则](https://pppoker.mn/zh/articles/holdem-guize-quan/)
- **Omaha** 6-max — [Omaha 规则](https://pppoker.mn/zh/articles/omaha-guize-quan/)
- 从 250/500 盲注开始

## 账号安全

- 密码不要告诉任何人
- 只使用官方 Telegram：@BatrynOrooSupport
- 阅读[账号安全](https://pppoker.mn/zh/articles/zhanghu-anquan/)

可以。许多玩家使用蒙古手机号注册。
