# Account Security — Safe Online Poker

## Core rules

1. **Password** — 12+ characters, unique, not reused elsewhere
2. **Device** — be careful on public Wi‑Fi; use app lock
3. **Official app only** — [mongol poker download](https://pppoker.mn/en/articles/mongol-poker-download/)
4. **OTP and codes** — never share with anyone, including «support»
5. **Logout** on shared devices

## Spotting phishing

| Scam | Real |
|------|------|
| Random «bonus» link in chat | pppoker.mn or in-app cashier |
| New Telegram account DMing you | Only @BatrynOrooSupport |
| Asks for password or OTP | Never asks for password |
| Urgent «account locked» link | Check official app first |
| Fake club ID in group chat | Get ID from support only |

Scammers copy Baatryn Öröö branding. Verify every link and username.

## If your account is compromised

1. Change PPPoker password immediately
2. Log out all devices (support can help)
3. Message @BatrynOrooSupport — mark urgent
4. Contact your bank if unauthorized transfers occurred
5. File police report for large theft

Speed matters. The faster you report, the better the chance to freeze outgoing funds.
