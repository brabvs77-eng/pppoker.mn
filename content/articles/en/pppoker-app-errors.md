# PPPoker App — Install and Fix Errors

**PPPoker app** install and login issues are common. Mongolian players in Ulaanbaatar and the regions often hit network problems, outdated versions, or unofficial APK files. This guide fixes the usual cases so you can get back to the table.

Most problems resolve with an official reinstall and a stable connection.

## Check these first

1. Stable internet (Wi‑Fi or 4G)
2. Latest app version installed
3. Enough phone storage (500MB+ free)
4. Correct date and time (set to automatic)
5. Official download source — [mongol poker download](https://pppoker.mn/en/articles/mongol-poker-download/)

## Android errors

| Error | Fix |
|-------|-----|
| «Cannot install» | Settings → Security → Allow installs from this source |
| App won't open | Clear cache, force stop, reinstall |
| «Network error» | Turn off VPN, switch Wi‑Fi or mobile data |
| Old version | Download latest official APK |
| «Parse error» | Corrupt download — delete and re-download |

## iOS errors

1. App Store → PPPoker → Update
2. Check minimum iOS version on the store page
3. Apple ID region — some players need a supported region
4. Delete and reinstall — account data is kept on PPPoker servers
5. Restart iPhone after update

## Windows / macOS

- Download official PPPoker desktop client from the global site
- Temporarily disable antivirus during install (re-enable after)
- Run as administrator on Windows
- macOS: allow app in System Settings → Privacy if blocked

## Login errors

- **Forgot password** → use «Forgot password» in app
- **Club not visible** → re-enter club ID from [@BatrynOrooSupport](https://t.me/BatrynOrooSupport)
- **«Account locked»** → message support with your registered phone/email
- **Wrong verification code** → check SMS delay, request new code

Complete [registration](https://pppoker.mn/en/articles/registration-step-by-step/) before expecting club tables.

## Deposit not showing

1. Confirm club membership is approved
2. Check transfer matched instructions exactly
3. Wait up to 4 hours for IBAN processing
4. After 4+ hours → support with transfer receipt

## FAQ

### Should I use a VPN?

Usually not needed in Mongolia. Some VPNs are blocked by PPPoker and can lock accounts.

### Two phones, one account?

One account works on multiple devices. You cannot play two tables on two devices simultaneously.

### Does the app support Mongolian?

PPPoker supports many languages. Club support is available in Mongolian, Russian, and English.

### App crashes mid-hand?

Update the app, restart device, check connection. Contact support if chip balance looks wrong after reconnect.
