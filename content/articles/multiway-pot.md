# Multiway pot — 3+ тоглогч

**Multiway pot** нь 3 ба түүнээс олон тоглогч флоп хүртэл үлдсэн үе. [Baatryn Öröö](https://pppoker.mn/) 9-max ширээнд байнга тохиолдоно. Нэг тоглогчид vs олон — стратеги өөр.

## Гол зарчим

- **Илүү хатуу** — premium гар л тогло
- **Bluff багасга** — нэг хүн fold хийхэд бусад call хийж болно
- **Value том** — олон call = илүү мөнгө

## Префлоп

- EP-ээс сул гар open бүү хий — multiway болно
- Iso-raise: limper олон бол хүчтэй гар л raise
- [Префлоп](https://pppoker.mn/articles/preflop-strategi/) range нарийсгах

## Флоп c-bet

| Тоглогч | C-bet частот |
|---------|--------------|
| Heads-up | 55–70% |
| 3-way | 30–40% |
| 4+ | 20–30% |

Зөвхөн хүчтэй гар, dry борд.

## Draw

- [Pot odds](https://pppoker.mn/articles/pot-odds-equity/) илүү сайн — олон тоглогч pot том
- Implied odds өндөр — nut draw л хөөнө
- Reverse implied odds — сул draw-аас зайл

## Позиц

IP multiway-д илүү ашигтай — хамгийн сүүлд үйлдэл.

[Позицийн хүч](https://pppoker.mn/articles/pozitsiin-huch/) чухал.

## Практик

1. Multiway-д top pair — бага bet, call их
2. Set, two pair — value bet том
3. Air — check/fold ихэвчлэн

## Түгээмэл асуултууд

### Multiway bluff хийх үү?

Маш ховор. Зөвхөн бүх тоглогч weak харагдах үед.

### 9-max ширээ

Baatryn Öröö 9-max — multiway байнга. Тэсвэртэй range сурах.
