# 3-bet ба 4-bet — префлоп агресси

**3-bet** нь open raise-д re-raise. **4-bet** — 3-bet-д дахин raise. [Baatryn Öröö](https://pppoker.mn/) 9-max ширээнд префлоп шийдвэр ихэнхи ашгийг тодорхойлно.

## 3-bet төрлүүд

| Төрөл | Гар | Зорилго |
|-------|-----|---------|
| Value | AA, KK, QQ, AK | Сул гарыг мөнгө оруулах |
| Bluff | A5s, KQs, 76s | Fold equity |
| Merge | TT, AQ | Value + bluff balance |

## Позиц чухал

- **EP 3-bet** — маш хатуу (AA–KK, AK)
- **BTN vs CO open** — илүү өргөн bluff
- **BB 3-bet** — defense + value

[Позицийн хүч](https://pppoker.mn/articles/pozitsiin-huch/) + [префлоп](https://pppoker.mn/articles/preflop-strategi/).

## 3-bet хэмжээ

- IP: open-ийн **3x**
- OOP: open-ийн **3.5–4x**
- Жишээ: 3BB open → 9–10BB 3-bet

## 4-bet

- Value: AA, KK (заримдаа QQ, AK)
- Bluff: A5s, KQs — бага частот
- Хэмжээ: 20–25% stack эсвэл all-in (100bb-д)

Эхлэгчид 4-bet bluff багасга.

## Call 3-bet

Call хийх гар:
- Pocket pairs (set mine) — 22–99
- Suited connectors — позиц сайтай
- AQ, JJ — позицоос

Fold ихэнх сул гар.

## Практик дүрэм

1. Value 3-bet-ээс эхэл
2. Bluff — зөвхөн BTN, CO
3. 4-bet = premium эсвэл бүү хий
4. [Банкролл](https://pppoker.mn/articles/bankroll-udirdlaga/) — 3-bet pot том

## Түгээмэл асуултууд

### 3-bet-д бүх гар call хийх үү?

Үгүй. Fold ихэвчлэн зөв.

### Squeeze (overcall дээр 3-bet)?

Тусгай тактик — дараа нь. Эхлээд суурь 3-bet.
