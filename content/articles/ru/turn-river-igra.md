# Игра на терне и ривере

**Терн** и **ривер** — улицы, где pot максимален. На столах [Baatryn Öröö](https://pppoker.mn/?lang=ru) здесь выигрывают или проигрывают больше всего. После [основ постфлопа](https://pppoker.mn/ru/articles/postflop-osnovy/) этот framework структурирует решения на поздних улицах.

База: [c-bet стратегия](https://pppoker.mn/ru/articles/cbet-strategiya/) + [чтение range](https://pppoker.mn/ru/articles/chtenie-range/).

## Решения на терне

| Рука | Действие |
|------|----------|
| Nut / сильная | Value bet |
| Draw | Semi-bluff или call ([pot odds](https://pppoker.mn/ru/articles/pot-odds-ekviti/)) |
| Marginal (second pair) | Pot control — check |
| Air | Check/fold, иногда bluff |

Терн меняет борд: flush card, pair board, straight card. Пересчитайте range соперника после новой карты.

## Double barrel (две улицы подряд)

Флоп c-bet → терн bet = double barrel.

Когда продолжать:
- Борд не сильно изменился в пользу caller
- У вас range advantage
- Соперник fold to double barrel часто

Когда остановиться:
- Wet терн card (flush, straight закрылся)
- Вы bluff без equity
- Соперник calling station

Размер: [размер ставок в покере](https://pppoker.mn/ru/articles/razmer-stavok-poker/) — терн 50–66% pot стандарт.

## Ривер — два пути

На ривере решение проще:

1. **Value** — слабая рука соперника может call
2. **Bluff** — есть fold equity
3. **Check** — showdown достаточен или bluff catch

Средний bluff на ривере — частая ошибка. Либо крупный bluff с blockers, либо check. Полублеф 33% pot на ривере редко работает.

## Thin value

Top pair, second pair — **тонкий value** на ривере:

- Bet 25–33% pot — слабые руки call
- Не overbet — worse не call
- Против calling station — bet чаще

Пример: борд K83T2, у вас KQ (top pair). Ривер bet 30% — Kx, 88 call. Check — упускаете value.

## Bluff catch

**Bluff catch** — call на ривере, ожидая bluff.

Когда call:
- Соперник bluff часто ([статистика покера](https://pppoker.mn/ru/articles/statistika-pokera/))
- Линия выглядит как bluff (check-call, check-call, bet)
- У вас bluff catcher (top pair weak kicker)

Когда fold:
- Соперник value-heavy (never bluff)
- Линия = value (raise флоп, bet терн, bet ривер)
- [Искусство блефа](https://pppoker.mn/ru/articles/iskusstvo-blufa/) — знайте, кто блефует

## SPR (Stack-to-Pot Ratio)

SPR = effective stack / pot.

- **SPR < 3** — all-in решения на терне/ривере
- **SPR 3–6** — одна-две улицы value
- **SPR > 10** — много улиц, pot control важнее

Пример: pot 30BB, stack 60BB, SPR = 2. Top set на терне — часто all-in. Pot 10BB, stack 100BB, SPR = 10 — можно check-call несколько улиц.

## Терн check-raise

Сильная рука или combo draw на терне — [check-raise](https://pppoker.mn/ru/articles/check-raise-taktika/):

- Set после c-bet флоп + bet терн
- Nut flush draw после double barrel
- OOP с сильной рукой — вернуть инициативу

Check-raise терн сильнее сигнал, чем флоп.

## Ривер и range

К риверу range соперника самый узкий. Используйте [чтение range](https://pppoker.mn/ru/articles/chtenie-range/):

- C-bet, call, check терн, bet ривер = value (80%+)
- Check-call, check-call, check = weak, bluff catch с marginal
- Bet, bet, bet = polarized (nuts или bluff)

## Multiway на терне/ривере

В [multiway pot](https://pppoker.mn/ru/articles/multiway-pot/) поздние улицы опаснее:

- Меньше bluff
- Value только с сильной рукой
- Check-call с top pair — осторожно

## Практический framework

**На терне спросите:**
1. Улучшилась ли моя рука?
2. Борд опаснее или безопаснее?
3. SPR — all-in или ещё улица?
4. Соперник fold на pressure?

**На ривере спросите:**
1. Value или bluff — одно из двух?
2. Worse call? → value
3. Better fold? → bluff или check
4. Showdown enough? → check

## Типичные ошибки

- Bluff 3 улицы подряд без плана
- Check back value на ривере
- Call ривер без bluff catch justification
- Игнорировать SPR — all-in с marginal

## Терн в 3-bet pot

В 3-bet pot SPR низкий — терн часто решающая улица. C-bet флоп, bet терн all-in с top pair+ или strong draw. Check терн с marginal — pot control не нужен при SPR 2–3.

Связь: [3-bet и 4-bet стратегия](https://pppoker.mn/ru/articles/3bet-4bet-strategiya/) + [c-bet стратегия](https://pppoker.mn/ru/articles/cbet-strategiya/).

## River blockers

Bluff на ривере сильнее с blockers:

- Nut flush block (A♠ на 4-flush board) — у соперника меньше nut flush
- Top pair block — меньше value combinations

Без blockers bluff на ривере рискованнее. Теория: [искусство блефа](https://pppoker.mn/ru/articles/iskusstvo-blufa/).

## FAQ

### Check-call на ривере — мало?

Зависит. Против value bet — fold marginal. Против suspected bluff — call. Против station — fold bluff catchers, value bet yourself.

### Терн check-raise — когда?

Сильная рука (set, two pair) или combo draw. После агрессии c-bettor на флопе и терне.

### River = value или bluff?

Полярное решение. Средние руки — check. Top pair+ vs weak range — value. Air vs fold-happy — bluff.
