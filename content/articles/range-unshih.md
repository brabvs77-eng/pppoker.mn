# Range унших — суурь

**Range** нь тоглогч тодорхой нөхцөлд ямар гар тоглож болох вэ гэсэн багц. Range унших = шийдвэр сайжруулах. [Baatryn Öröö](https://pppoker.mn/) ширээнд практик дэдээс эхэл.

## Range гэж юу вэ?

Жишээ: BTN open = 40% гар (AA, 72o, suited connectors...). Нэг гар биш — бүх боломжит гарууд.

[Префлоп](https://pppoker.mn/articles/preflop-strategi/) range мэдэх.

## Алхам 1: Префлоп action

| Action | Range |
|--------|-------|
| UTG raise | Хатуу (10%) |
| BTN raise | Өргөн (40%) |
| 3-bet | Premium + bluff |
| Call | Дунд зэрэг |

## Алхам 2: Флоп action

- C-bet = range-д илүү сайн гар
- Check = сул эсвэл trap
- Raise = хүчтэй

## Алхам 3: Narrow

Street бүр range нарийсна:

**Жишээ:** BTN open → флоп c-bet → терн check → river bet = ихэвчлэн value

## Blockers

Таны карт тэдний range-ийг хаах:

- A♠ гарт — nut flush бага
- [Блеф](https://pppoker.mn/articles/blef-uriag/) bluff-д blocker чухал

## Практик

1. Префлоп action → эхний range
2. Постфлоп action → нарийсгах
3. [Эксплойт](https://pppoker.mn/articles/exploitation-taktik/) — range-ийн сул тал

## Түгээмэл асуултууд

### Range яг мэдэх үү?

Тийм биш. Магадлал. «Тэр AA байж магадгүй» — %.

### [Turn-river](https://pppoker.mn/articles/turn-river-play/) холбоо?

Терн, ривер range хамгийн нарийн.
