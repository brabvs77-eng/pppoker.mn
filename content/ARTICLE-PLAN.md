1. thruuu brief with Content Outline (headings sacred)
2. Zipf tier from `knowledge/semantic-core.md`
3. Ski-ramp intro + club CTA (`GUIDELINE.md`)
4. Internal links: 2+ to published articles, 1+ to pillar
5. `Stage: final` → `npm run articles:build && npm run build`
6. GSC: inspect after 2–4 weeks (`npm run gsc:export`)
